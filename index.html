Glitch Launcher

Neon CATCH home screen for Android. Download the APK, install it, then set it as your Home app.

Open live demo
  1. Tap Download APK and open the file on your phone.
  2. Allow installs from this source if Android asks.
  3. Open Glitch Launcher.
  4. Go to Settings → Apps → Default apps → Home app and pick Glitch Launcher.
  5. Press the Home button. The CATCH lock screen and your real apps should appear.

To switch back later: Settings → Default apps → Home app → your old launcher.
